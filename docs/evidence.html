Evidence

Each claim about cancho-hooks, with the test in the repository that checks it and the section of the design document that records the result; then what it costs, each figure with its method. How the tests are built is in testing.md.

What has been tested, and how

Each row is a test in the repository, run by CI, with the design section that records the result. Where a row gives a number of checks, it is the number the test reports (the lines it prints as passed) on a run of the commit this page describes. Times come from runs on a shared development machine and are not a throughput benchmark: “What it costs” below has the figures there are, with their methods; docs/capacity.md is the method in one place.

What it costs

Measured on a shared 4-core VM (Intel Xeon 2.10 GHz) that other work was also using, so each figure is a bound and a few percent is noise; these are measurements of this service, not a benchmark against any other. A range is the spread of the runs. Each row says where its method is written down; docs/capacity.md gives the method in one place, and its long-run cells are empty until the 24-hour run is made.
